Methodology & formulas

Layer technical pricing

  • CoV = σ / EL — coefficient of variation of layer loss
  • Risk Load = λ × σ — standard-deviation risk loading, the classic actuarial risk-adjusted premium principle. Enter a value directly in the "Risk load ($M) override" column to bypass this formula for a layer (e.g. to use a number from another model or a negotiated load) — a "custom" badge marks any layer using an override.
  • Technical Premium = EL + Risk Load
  • Gross Premium = Technical Premium / (1 − Expense Ratio), then floored at ROL Floor × Limit if higher
  • ROL = Gross Premium / Limit
  • Multiple of EL = Gross Premium / EL — the market "rate-to-EL" multiple
  • Payback (years) = Limit / Gross Premium

Reinstatements

Expected reinstatement premium approximates the expected fraction of the layer limit eroded by loss (EL / Limit, capped at the number of reinstatements purchased) and charges it at the reinstatement rate: Expected Reinstatement Premium = Gross Premium × Reinstatement Rate × min(Reinstatements, EL / Limit). This is a simplified expected-value approximation, not a full simulation.

Tower aggregation

Layer standard deviations are combined assuming independence between layers: Tower σ = √(Σ σi2). If your cat model provides a correlated/aggregate tower standard deviation, use that instead of relying on this approximation.

Notes

Expected Loss (EL, a.k.a. AAL) and layer standard deviation should come from your catastrophe model output for each layer. λ is a market price of risk you calibrate — higher λ produces more conservative (higher) technical pricing. A floor badge appears on a layer when the minimum ROL floor binds ahead of the technical (EL + risk load) price.

All calculations run locally in your browser. Nothing is sent anywhere — use Export JSON to save a tower.
